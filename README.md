# Proyecto2-Archivos-SS26
Segundo proyecto del curso de Archivos - Universidad de San Carlos de Guatemala-CUNOC - Conciste en hacer un Sistema de Gestion Documental (Mini Google Drive) que permita almacenar, oraganizar, consultar y compartir archivos digitales entre diferentes usuarios - Tecnologias utilizadas: Angular 21, NodeJS 24, ExpressJS 5 y MongoDB 8
